# irr — 賃金を世界株へ積み立てた場合のIRR研究

**リポジトリ:** https://github.com/KAFKA2306/irr

日本の賃金・賞与データをもとに、一定額を世界株式ETFへ積み立てたと仮定した場合の内部収益率（IRR）を、就業開始年ごとに比較する研究プロジェクトです。

開始時期による資産形成結果の差を調べることが目的ですが、過去のREADMEに掲載されていた有意差、効果量、資産差、データ完全性などは、入力データと再現可能な出力を同時に確認しない限り、確定した研究結果として扱いません。

## 研究する問い

- 就業・積立開始年によってIRRはどの程度変わるか
- 賃金上昇と市場リターンのどちらが資産形成へ強く影響したか
- 金融危機、円高・円安、株価上昇局面が各コホートへどう影響したか
- 投資期間の長さをそろえた場合でも差が残るか
- 月次積立と一括投資で結果がどう変わるか

## 基本的な処理

```text
賃金・賞与データを取得または読込
  → 月次の投資可能額を定義
  → ACWI系価格データを取得
  → 配当・分割・為替の扱いを決める
  → 開始年ごとのキャッシュフローを生成
  → IRRと資産残高を計算
  → 同じ投資期間でコホートを比較
  → 統計検定と感度分析
```

## データ源

想定している主なデータ源:

- e-Statの賃金関連統計
- Yahoo Finance等の市場価格データ
- ACWI連動ETFまたは代替指数

以前の分析では、e-Stat APIの制約に対応するためサンプルデータを使った記録があります。サンプルデータを公式統計と同一視しないでください。

## IRRの定義

月次キャッシュフロー`CF_t`に対して、次を満たす利率を求めます。

```text
Σ CF_t / (1 + r)^(t/12) = 0
```

積立額を支出として負、評価時点の資産を正として入力します。月次IRRを単純に12倍するのではなく、使用した年率換算方法を明示してください。

## 比較で固定すべき条件

- 各コホートの投資期間
- 賃金の産業・年齢・雇用形態
- 賞与を含むか
- 投資割合
- ETFまたは指数
- 円建て・外貨建て
- 配当再投資
- 為替換算日
- 手数料、税、スプレッド
- 退職・失業・投資停止の扱い

期間が短い後期コホートと長い初期コホートをそのまま比べると、開始時期以外の影響が混ざります。

## 出力

このプロジェクトはYAMLを中心に、入力条件、月次キャッシュフロー、IRR、評価値、統計結果を保存する設計です。

推奨出力:

```yaml
cohort_start: 2010-01
analysis_end: 2025-12
wage_source: "..."
market_source: "..."
asset: "..."
currency: JPY
contribution_rule: "..."
irr_annualized: 0.0
terminal_value_jpy: 0
assumptions: []
```

## 統計検定の注意

- 開始年ごとの結果は独立標本とは限りません
- 同じ市場期間が重なるため自己相関があります
- コホート数が少ないとp値は不安定です
- 複数比較を行う場合は補正が必要です
- 効果量と信頼区間を併記してください
- 正規性を仮定する検定だけに依存しないでください

以前のREADMEにあった`p=0.012`や`Cohen's d=1.17`は、分析コード、入力、比較群を再実行して確認するまで参考値としても使用しません。

## 再現性チェック

1. 元統計の系列IDと取得日を保存する
2. サンプルデータと公式取得データを区別する
3. 価格系列が調整済みか確認する
4. 月次日付の対応規則を固定する
5. すべてのコホートで評価期間をそろえる分析も行う
6. 手数料と税を変えた感度分析を行う
7. 入力・設定・出力へハッシュを付ける
8. READMEへ固定結果を転記せず、生成レポートを正とする

## 注意

- IRRはキャッシュフローの時期に強く依存します
- ACWI連動ETFの実績と指数リターンは一致しません
- 日本居住者の実際の税・為替・手数料を完全には再現しません
- 過去の開始時期比較は将来の最適な開始時期を示しません
- 本プロジェクトは投資助言、年金設計、将来資産の保証ではありません
